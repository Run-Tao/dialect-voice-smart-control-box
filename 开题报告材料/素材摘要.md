## 来源 1：项目建议书_正式版.md（docs/项目建议书_正式版.md）
- 项目名称：基于方言语音识别的智能家居语音转换装置；本科工程导论项目，周期约 2 个月，预算 1000 元以内。
- 背景：老年人习惯方言，主流智能家居面向普通话；智能音箱封闭、难接入。装置端侧识别方言→置信度判断→普通话播报给音箱执行，保留串口/继电器直控备用。不改音箱固件、不依赖厂商 API。
- 目标：6 条固定家居命令（开灯/关灯/开窗帘/关窗帘/全部关闭/查询状态）；端侧实时识别；低置信度不执行；OLED 显示；双备用通道。
- 技术路线：方言语音→VAD→log-mel40+Δ（整句 CMVN）→1D-CNN 3 种子集成→温度标定置信度→阈值拒识→语义层映射→普通话播报/串口下发。
- 九节结构：背景意义 / 前期基础 / 目标 / 技术路线 / 系统方案 / 硬件预算 / 数据采集实验 / 进度 / 风险 / 预期成果 / 参考文献。
- 关键判断：原「方言→普通话特征映射」主线因下游准确率 0.1667（六类随机水平）被否决，改为端侧直接分类+拒识+语义层播报。
- 硬件预算：合计约 305–1085 元（树莓派 0–400 那一项已过时，主控后确认为 ESP32-S3，见来源 5）。
