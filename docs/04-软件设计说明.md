# 04 · 软件设计说明

## 1. 模块总览

| 文件 | 职责 | 关键接口 |
|---|---|---|
| `audio.py` | 音频 I/O 与重采样 | `load_wav / save_wav / record / to_mono_16k → AudioClip` |
| `textutils.py` | 中文数字、口音模糊拼音 | `cn2num / extract_numbers_with_unit / fuzzy_pinyin` |
| `normalize.py` | 繁简、粤语词表、冗余词、数字归一 | `normalize(text) → str` |
| `understand.py` | 命令库加载 + 双通道意图/槽位解析 | `CommandLibrary / Understander.parse → Command` |
| `asr/` | 可插拔 ASR 后端 | `AsrBackend.transcribe(clip, language) → AsrResult` |
| `executor/` | 可插拔执行器 | `Executor.execute(cmd, action_spec) → ExecResult` |
| `tts.py` | 离线/在线语音反馈 | `Tts.speak(text, block)` |
| `pipeline.py` | 编排 + 指标日志 | `Pipeline.process_wav / process_audio / process_text → PipelineResult` |
| `cli.py` | 命令行入口 | `--wav / --mic / --text / --backend / --lang` |
| `server.py` | Flask Web 服务 | `/api/recognize /api/text /api/state /api/reset` |
| `web/` | 浏览器录音前端 | AudioContext 采 16k PCM → WAV → POST |

## 2. 数据流与类型契约

```
AudioClip(samples: float32[n], sr=16000)
  → AsrResult(text, language, backend, ms)
  → normalize → str
  → Command(device, action, room, room_name, slots, confidence, matched_text)
  → ExecResult(ok, message, state)
  → PipelineResult(raw_text, language, backend, normalized_text,
                   command, ok, feedback, timings_ms, error)
```

所有环节耗时记入 `timings_ms`（asr / nlu / exec / load / total），
每次交互追加 JSONL 到 `data/results/interactions.jsonl`，供测试报告统计。

## 3. 理解层算法细节

### 3.1 归一化（normalize.py）
1. OpenCC `t2s` 繁→简；
2. 粤语词表按**长度降序**替换（冷气机→空调 先于 冷气→空调，避免子串误伤），
   并做**定点迭代**（≤4 轮）：短规则（D/滴→啲）会在本轮后期产出长规则
   （冻啲→冷一点）的输入，单遍替换会漏映射；规则集无环，迭代必收敛；
3. 删除礼貌/填充词（唔该、帮我、麻烦、请、一下…）；
4. 去标点空白；
5. 「X度/档/个台」中的中文数字→阿拉伯数字（含粤语合文 廿=20、卅=30、两=2）。

命令库别名在加载时做**同样归一化**，保证两侧在同一表示空间匹配。

### 3.2 双通道匹配（understand.py）
- **言语行为守卫**（先于匹配）：按语法标记类拒识非控制句——疑问（边个/谁/咩/吗/了未/动词+未）、
  完成体陈述（代词+了）、条件（如果/假如/一旦/就+控制动词）、意愿否定（唔想/唔使/不想/不要）、
  祈使否定（唔好/咪/米/别，**带词边界**避免误伤 妈咪/玉米/特别）、
  程度抱怨（太X/好X）、损坏/疑问/观看（坏/卡住/几钱/点解/睇/查）；
  守卫匹配**归一后**文本（咗→了）；
- **语素锚**：剔除设备/房间别名后的骨架须含控制语素（开关熄调较拉…），
  否则拒识——防止「空调」自带的「调」绕过锚；
- **原文通道**：归一文本子串命中别名 → 100 分，**精确命中优先于模糊命中**
  （模糊拼音鼻音合并存在 光≈关 同分碰撞）；
- **模糊通道**：`rapidfuzz.fuzz.partial_ratio` 在
  ① 模糊拼音串（音节级混淆归一：zh/z、ch/c、sh/s、n/l、f/h、ang/an、eng/en、ing/in）
  ② 原文字面 两个空间取最大分；单字核心（开/关）的拼音模糊仅在字面出现于骨架时启用；
- **骨架化**：从整句剔除已命中的设备/房间别名得到 skeleton，
  动作别名也剔除设备词得到 core，在 skeleton 上匹配 core——
  解决「关了**客厅**灯」这类房间词插入动宾之间的结构；
- **设备反推**：未提设备名时（「转台」「大声啲」），用动作别名反推唯一设备；
  动作别名精确命中反推的设备**优先于**设备名的模糊命中；
- **数值规则通道**：空调温度用正则（调到/调低/调高 + 数字 + 度）直接出槽位，
  比模糊匹配更稳；`set_temp` 缺数值则拒绝执行并提示；
- **槽位校验**：对精确/模糊两通道统一生效——`set_temp` 无温度数字一律拒识，
  不产出空槽指令；「调一点」无方向词时升降歧义拒识。

阈值：动作 78、设备/房间 85（短串要求更严，防误识）。

### 3.3 置信度
`confidence = min(动作分, 设备分) / 100`，写入日志与前端，便于后续按阈值拒识。

## 4. ASR 后端

| 后端 | 模型 | 语言 | 说明 |
|---|---|---|---|
| sensevoice（默认） | iic/SenseVoiceSmall + fsmn-vad | auto/yue/zh/en/ja/ko | 非自回归 CTC，CPU 实时；`use_itn=True`；富文本标签后处理剥离 |
| whisper（备用） | faster-whisper small int8 | zh 等 | 交叉验证/降级；HF 镜像下载 |
| mock（测试） | 无 | — | 读 wav 旁车 `.txt`，单元测试零模型依赖 |

模型缓存统一在项目 `models/`（`MODELSCOPE_CACHE` 指向该目录），整项目可离线搬移。

## 5. 执行器

- **simulator**：5 房间 × 6 设备状态机，温度 16~30 钳位、亮度 10~100、风速 1~3、
  频道 1~99 回绕；反馈模板来自命令库 `feedback` 字段；
- **mqtt**：`dialecthome/cmd/<room>/<device>` 发布 `{"action":…, …slots}`，QoS1；
- **homeassistant**：(device,action)→(domain,service) 映射表 + REST 调用，
  entity_id 约定 `<domain>.<room>_<device>`。

## 6. Web 前端

- `AudioContext + ScriptProcessorNode` 直接采 PCM，线性插值降采样到 16 kHz，
  JS 手工封装 WAV 头——**不依赖 MediaRecorder/ffmpeg**，跨浏览器格式一致；
- 最长 15 s 自动停止；`POST /api/recognize` multipart 上传；
- 识别链路四段可视化（原文/归一化/命令 JSON/反馈）+ 耗时；
- 设备状态面板 5 s 轮询 + 执行后即时刷新；文本调试框直测理解层。

## 7. 扩展指南

- **加设备/说法**：编辑 `config/commands.yaml`（别名收粤语+普通话），无需改代码；
- **加方言**：在 `normalize.py` 词表加该方言→普通话映射；ASR 若不支持该方言，
  可换 whisper 后端或微调（后续工作）；
- **加执行目标**：实现 `Executor` 子类并在 `executor/__init__.py` 注册；
- **接真实麦克风阵列按键**：GPIO 中断 → `audio.record()` → `Pipeline.process_audio`。

## 8. 测试策略

- 单元：数字转换 / 归一化 / 49 条理解用例（含口音错字、实测 ASR 变体、守卫词边界）/
  非控制言语行为拒识 / 执行器状态机 / mock 流水线；
- 鲁棒/拒识：文本通道 38 正例 + 37 负例（`scripts/run_eval_robust.py`），引擎改动回归门槛；
- 端到端：40 条 TTS 合成语料（26 粤语 + 14 普通话），统计意图/房间/槽位/完全正确率与延迟；
- 云端契约：ESP32 适配层逐字段比对（`esp32-dialect-voice/backend/eval_cloud.py`）；
- 口径：合成语料指标 ≠ 真实录音指标，测试报告分别标注并给出真实验证规程。
