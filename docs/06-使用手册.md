# 06 · 使用手册

## 1. 环境准备（Windows 开发机）

```bat
cd D:\Projects\dialect-smart-home
D:\anaconda3\envs\py_study\python.exe -m venv .venv
set PYTHONUTF8=1
.venv\Scripts\python.exe -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

> `PYTHONUTF8=1` 必须：requirements.txt 含中文注释，GBK locale 下 pip 会解码失败。
> 树莓派部署见 docs/03 §3.4。

## 2. 下载模型（首次运行前）

```bat
.venv\Scripts\python.exe scripts\download_models.py
```

从 ModelScope 国内源下载 SenseVoiceSmall（约 900 MB）与 fsmn-vad 到 `models/`，
无需代理。可选 `--whisper` 下载备用模型（走 hf-mirror）。

## 3. 三种使用方式

### 3.1 Web 界面（推荐演示）

```bat
run_web.bat
```

浏览器打开 http://127.0.0.1:8000 ：
1. 点击圆形麦克风按钮开始录音（最长 15 s），再次点击结束；
2. 页面显示：ASR 原文 → 归一化 → 结构化命令 → 执行反馈 → 各环节耗时；
3. 右侧「虚拟家居状态」面板实时显示 5 房间 × 6 设备状态；
4. 也可在文本框直接输入指令（如 `冷气较低两度`）测试理解层，无需麦克风。

示例指令（粤语）：
- 「唔该帮我熄咗客厅盏灯」
- 「冷气调到二十六度」
- 「拉埋卧室窗帘」
- 「电视大声啲」

### 3.2 命令行

```bat
rem 识别音频文件
.venv\Scripts\python.exe src\dialect_home\cli.py --wav data\corpus\yue01.wav

rem 麦克风录音 5 秒后识别
.venv\Scripts\python.exe src\dialect_home\cli.py --mic 5

rem 文本直测理解层
.venv\Scripts\python.exe src\dialect_home\cli.py --text "冷气较低两度"

rem 指定语言/后端/静音
.venv\Scripts\python.exe src\dialect_home\cli.py --wav x.wav --lang yue --backend whisper --no-tts --json
```

### 3.3 Python API

```python
import sys; sys.path.insert(0, "src")
from dialect_home.pipeline import Pipeline

pipe = Pipeline()
res = pipe.process_wav("data/corpus/yue01.wav")
print(res.command, res.feedback, res.timings_ms)
```

## 4. 接入真实家居

编辑 `config/settings.yaml`：

```yaml
executor:
  type: mqtt            # 或 homeassistant
  mqtt: {host: 192.168.1.10, port: 1883, topic_prefix: dialecthome/cmd}
```

- MQTT：设备端订阅 `dialecthome/cmd/<room>/<device>`，payload 为
  `{"action": "turn_off", ...}`；
- Home Assistant：填 `url` 与长期访问令牌 `token`，
  entity_id 约定 `<domain>.<room>_<device>`（如 `light.living_room_light`）。

## 5. 扩展命令库

编辑 `config/commands.yaml`，例如加「加湿器」：

```yaml
devices:
  humidifier:
    name: 加湿器
    aliases: [加湿器, 加湿机]
    actions:
      turn_on: {aliases: [开加湿器, 打开加湿器], feedback: "已打开{room}的加湿器"}
      turn_off: {aliases: [关加湿器, 熄加湿器], feedback: "已关闭{room}的加湿器"}
```

保存即生效（重启服务），无需改代码。粤语说法直接写进 aliases，
或在 `normalize.py` 词表加映射。

## 7. 常见问题

| 现象 | 原因/处理 |
|---|---|
| pip 安装报 UnicodeDecodeError | 未设 `PYTHONUTF8=1` |
| 首次识别很慢 | 模型加载（一次性），后续请求正常 |
| 浏览器无法录音 | 非 localhost 访问需 HTTPS；用 127.0.0.1 打开 |
| 没有语音播报 | 系统缺中文语音包；Windows 设置→语音→添加「中文(简体)」 |
| edge-tts 合成失败 | 需代理：`--proxy http://127.0.0.1:7890` |
| 识别为「未识别到指令」 | 说法未登录命令库；按 §5 扩展别名 |
| 内存不足（树莓派） | 关桌面环境或改 q8 量化运行时（docs/03） |
