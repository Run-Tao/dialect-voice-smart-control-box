# 方言智控盒软件优化报告

日期：2026-10-18

## 1. 优化方向

在保持原分类器、DTW、模拟控制和日志功能不变的前提下，优先做两项优化：

1. DTW帧数参数选择：用验证集选择，不使用测试集调参。
2. 用DTW替换部分控制路径：提升表达模板留出条件下的识别率，并重新校准拒识阈值。

## 2. 优化前/后对照

### 说话人隔离DTW基线

| 配置 | Val Accuracy | Test Accuracy | Test Macro-F1 |
|---|---:|---:|---:|
| max_frames=40（旧） | 0.467 | 0.367 | 0.361 |
| max_frames=60（新） | 0.733 | 0.433 | 0.432 |

`max_frames=60`由验证集选择，测试集只用于最终报告。

### 控制模型（表达模板留出）

- 训练：direct/colloquial/polite
- 验证：question
- 测试：correction

| 模型 | Val Accuracy | Test Accuracy | Test Macro-F1 |
|---|---:|---:|---:|
| 原Softmax控制模型 | 0.500 | 0.167 | 0.127 |
| 新DTW控制模型(max_frames=60) | 0.958 | 0.625 | 0.622 |

## 3. 拒识与控制安全

DTW评估模型阈值由验证集+未知校准集选择（target FAR=0.1）：

- threshold = 0.68
- 已知测试覆盖率 = 0.25
- 接受样本准确率 = 1.00
- 未知测试误接受率 = 0.00
- 未知测试拒识率 = 1.00

说明：这是以低覆盖换取高安全性的保守策略，不能只报告Accuracy。

## 4. 端到端结果

DTW演示模型（全量合成粤语TTS训练，阈值0.90）依次执行：
LIGHT_ON, LIGHT_OFF, CURTAIN_OPEN, CURTAIN_CLOSE, ALL_OFF, STATUS_ALL。

实际结果：6条全部正确识别，全部产生ACK，设备状态按预期更新。
一个未知命令样本置信度0.421 < 0.90，被拒识，设备状态保持不变。

注意：演示音频来自训练分布，不是泛化评估。

## 5. 测试

实际执行：40项单元测试通过。

## 6. 遗留问题

- 仍无真人粤语数据。
- 拒识高安全策略导致已知命令覆盖率较低。
- DTW推理比分类器慢，单次未知样本约1.76秒。
- 未知测试集仅12条合成TTS。
- 未接入真实ESP32-S3。


## 审计补充

- 数据清单180条与实际180个WAV一致。
- 说话人划分只隔离音色，未隔离文本；严格同时隔离音色与表达时测试Accuracy=0.167，说明现有较高指标依赖已见音色/表达。
- 评估模型阈值0.68与演示模型阈值0.90属于不同模型，已分别记录。
